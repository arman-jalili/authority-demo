# operator/ — the authority the agent cannot forge

This directory is the **source** of the operator-owned authority check. It is
committed here so the demo is self-contained, but it is *not* the live copy:

```
.rigorix/scripts/setup-authority.sh
        │  copies
        ▼
$HOME/.rigorix-authority-demo/
        ├── check-beneficiary.mjs   ← the live check
        └── authority.json          ← the live authority
```

The gate config (`.rigorix/preconditions.toml`, generated by the same script)
points at the **absolute path** under `$HOME`. That is the trust boundary:

- The **check binary** resolves outside the agent-writable workspace, so an
  agent cannot substitute a permissive check.
- The **authority file** lives outside the repo, so an agent cannot edit the
  rule it is judged by. The PreToolUse hook denies those writes too, but the
  boundary holds even without the hook — the repo simply does not contain the
  live file.

`authority.json` maps a beneficiary to a status:

| status    | effect |
|-----------|--------|
| `active`  | check exits **0** → the payout may dispatch |
| `frozen`  | check exits **3** → the payout is **refused** |
| (absent)  | treated as `unknown` → refused (fail closed) |

The demo's turn is a single edit to that file: freeze the beneficiary *after*
the human says yes, and watch the already-approved run refuse at dispatch.
```bash
bash .rigorix/scripts/freeze_beneficiary.sh acme
bash .rigorix/scripts/thaw_beneficiary.sh   acme
bash .rigorix/scripts/show_authority.sh
```
